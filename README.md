# 充安智护

校园电动两轮车集中充电场景的早期风险预警原型系统。

## 功能范围

- 短时充电窗口风险识别：支持 3 / 5 / 10 分钟窗口切换。
- 双模态动态融合：融合时序风险分数与视觉异常分数。
- 统一风险分级：输出低风险、中风险、高风险。
- 闭环处置：事件记录、告警复核、联动干预、归档复盘。
- 系统联动：内置场站驾驶舱、摄像头识别、移动端告警预览和模型配置页。

## 前端运行

```bash
npm install
npm run dev
```

## 后端接口骨架

```bash
cd server
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

接口前缀为 `/api`，当前用于后续接入真实场站数据和模型推理服务。
